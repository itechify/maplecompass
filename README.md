# MapleCompass

A helper overlay for MapleStory Classic World. It reads the minimap title by ordinary screen capture and shows which map you are on. It never touches the game's memory, files or input ([ADR 0001](docs/adr/0001-observe-game-from-outside-only.md)).

Its map and mob data come from the files [OSMS Data Explorer](https://osmsdataexplorer.com) publishes, and its links open [NiaMeowDB](https://meowdb.com)'s pages ([ADR 0008](docs/adr/0008-map-and-mob-data-from-osms-data-explorer.md)).

## Layout

- `crates/compass-core`: the headless core (no OS or UI dependencies). Title Region frames go in, a panel state comes out. It is the only test seam.
- `src-tauri`: the Tauri v2 shell. It finds the "MapleStory" window and moves the overlay with it (20 times a second), and on a thread of its own captures and reads the Title Region the player marked at setup about 3 times a second, feeding the readings to the core. It also fetches OSMS Data Explorer's five data files (under 1 MB, one at a time) at startup when its saved set is a day old, and again every 24 hours while it runs. From them the core knows every map's mobs, portals and Map Summary and every mob's Mob Card, snaps readings to the map list, and searches the whole world from the first launch. The set is saved in `%LOCALAPPDATA%\com.itechify.maplecompass\cache` and used offline after that; once OSMS hasn't been reached for over a week, the panel says it shows a saved copy, with its date. The shown map's picture and its listed mobs' animations are fetched from OSMS once, one at a time, and kept in the same folder until they go 30 days unused. MeowDB's caches from earlier versions are deleted at startup.
- `src`, `index.html`, `setup.html`, `region.html`: the web UI (vanilla TypeScript) for the overlay, the setup window and the title-marking window. It only renders state from the core.
- `samples/minimap`: test screenshots named `street-name__map-name[--variant].png`.

## Build, test, run (Windows)

Needs Rust (stable, MSVC), the Visual Studio C++ Build Tools, Node and pnpm.

```sh
cargo test                                      # core tests (the default workspace member)
cargo test -p maplecompass --lib                # the app's own unit tests
pnpm install
pnpm tauri dev                                  # run the overlay beside the game
pnpm tauri build --debug --no-bundle            # build target/debug/maplecompass.exe
cargo run -p maplecompass --example probe       # no UI: capture the title and print what the core reads
cargo run -p maplecompass --example probe osms  # no game: fetch OSMS's live data and read it in full
```

The tests run on made-up worlds in OSMS's shape and a list of the game's map names; `probe osms` checks the live data, by hand when OSMS changes and before a release.

Run the game windowed or borderless, with the minimap open.

On first run a setup window walks you through a ban-risk warning, finding the game window (or picking it by hand), the requirements, and marking the minimap title. Drag a box around its two lines, or use Arrow keys to move the box and Alt+Arrow to resize it; hold Shift for ten-pixel steps. Enter starts the test read and Esc returns to setup without changing the previous mark. These keys act only in MapleCompass's own marking window. A test read then shows the map it recognised; finish to start the overlay. The final step teaches the overlay shortcuts, and **Overlay Guide** in setup lists the current bindings and explains placement and hunting figures. Closing setup on first run quits. MapleCompass asks you to set up again when the game window changes size.

While it runs, the gold compass sits in the notification area (the tray). Click it for **Help & Setup** or **Quit MapleCompass**: the one way to quit, whether or not the game is open. Only one MapleCompass runs at a time: starting it again shows the one that is running (its panel, expanded, or setup when there is no game window to show the panel on).

The panel starts on the right edge of the game window, its top a third of the way down, and grows downward as its content changes. You can click it at any time, and a click never takes the keyboard from the game: only the search view (below) does. Drag it by its header to move it, or by a side or a bottom corner to make it wider or narrower (never under 320 px); its height follows what it shows. It is never taller than the room it has (the game window, or your screen when docked or detached); a long route or map list scrolls instead. It shows up in your screenshots and streams, and it never covers the minimap title, which MapleCompass reads: dragged onto it, it moves just clear of it when you let go. It shows on top of everything, but only while the game (or one of MapleCompass's own windows) is in front: while another app is, or the game is minimised, it hides. So opening a MeowDB page in your browser (a mob's, the map's, or an item's) hides it until you go back to the game. Once it knows your map it shows, from OSMS Data Explorer's data, the Map section first, then (with a Hunting Target, below) the Navigation section, then the Mobs: the map's Map Summary (EXP and mobs per hour, solo and 6+, worked out as MeowDB works them out) and its five most common mobs, sorted by level, with a line summing up the rest. Rest the pointer on a mob's name to see its Mob Card: the mob as OSMS animates it, and the figures its row doesn't show, such as its element, touch damage, accuracy, avoid and defences. Click the name to open the mob's MeowDB page, and the map's title to open the map's. The info icon at the bottom credits both when you hover it: "Data: OSMS Data Explorer (osmsdataexplorer.com) · Pages: NiaMeowDB (meowdb.com)". The title still drags the panel once you move the mouse. It is built like the game's own windows over the screen: a light grey bar with its name and blue buttons, the map's title on the Mini Map's sky blue, and the rest see-through like the Quest Helper. Collapsed, its icon shows the map's Hidden Portal count, with an orange dot when something needs a look.

The Map section shows OSMS's picture of the whole map, the Map Preview, on every map, towns included, with every portal ringed where it is: blue to another map, green within the map with a dashed arrow to where it lands, and grey to a map MapleCompass doesn't know. While you have a Hunting Target, each portal its route takes next from your map wears a wide magenta ring as well. Below it are the map's Hidden Portals: exits to other maps that OSMS's data marks invisible (type 1), hidden (10) or script (11, tagged Quest in violet), dashed on the picture. Each row shows where it leads (tagged when that is a Hidden Street). Rest the pointer on a ring to see where it leads, its street and its kind, and to light its row; rest it on a row to light its ring. Invisible exits on a town are its building doors, which you can see, so they are ringed like visible portals and not listed. A teleport within the map is never listed, though an invisible one is dashed, on a town too. Walk-into portals (type 3) count as visible until checked in-game. While the picture loads the section says "Loading map…", and if it can't be loaded, "Couldn't load the map picture" above the rows. A map with no picture and no Hidden Portals has no Map section. When play shows a portal the rule gets wrong, add it to the override list in `crates/compass-core/src/portal_overrides.rs`, by map ID and the portal's name in OSMS's `portals.json`.

Each of these also has a blue button in the bar at the top of the panel: a magnifier for search, two arrows for the next map with the same title (only when maps share it), a rising line to show or hide the Grind Tracker (when you track your EXP), two squares for placement, a gear for Settings, a question mark for Help & Setup, and a dash to collapse; click the collapsed icon to expand the panel again. Hover an icon to see its hotkey. The hotkeys work while the game or one of MapleCompass's windows is in front; in any other app the same keys do what that app makes them do:

- **Ctrl+Shift+C** collapses the panel to an icon, or expands it again.
- **Ctrl+Shift+P** switches placement: inside the game window, docked to its right edge, docked to its left edge, or detached.
- **Ctrl+Shift+M** opens the current map's MeowDB page in your browser, like a click on the map's title in the panel.
- **Ctrl+Shift+S** opens setup again, to mark the minimap title anew or consult the Overlay Guide.
- **Ctrl+Shift+N** shows the next map with the same title, when the panel can't tell which one you're on.
- **Ctrl+Shift+F** opens the search view, like the magnifier button at the top of the panel (expanding it if it is collapsed, or bringing it back in front if it is already open).
- **Ctrl+Shift+G** shows the Grind Tracker, or hides it.
- **Ctrl+Shift+I** opens the MeowDB page of the item you're hovering in the game: hover it until its tooltip shows, then press it.

The search view takes over the whole panel and takes your typing until it closes; then the game has focus again. Type part of a mob's name and pick the mob (arrow keys and Enter, or a click). The panel then lists every map it spawns on (but event maps and the developers' room, which routes never pass through either), ranked by Density Tier and then the nearest within a tier, each with its Density, Spawn Share and Distance, and the Taxis and Teleport Scrolls checkboxes. Pick a map the same way and it becomes your Hunting Target: the panel returns to the normal view with a Navigation section between the Map and the Mobs, showing the mob as OSMS animates it, the map, its figures, and the route there from the map you're on, worked out again as you move. When you arrive on that map the route gives way to "You're here", with how far you came, until you leave the map. Its magnifier reopens the mob's map list to pick another map, and its × clears it; like the Map and the Mobs, it collapses to its heading. The back arrow or Esc leaves the search view without changing anything. The Hunting Target lasts until you close MapleCompass.

Item Lookup (Ctrl+Shift+I) reads the item tooltip nearest the pointer (the inventory's, or any other window's drawn the same way) and looks its name up with MeowDB's search; the page opens in your browser. It reads the name on the line with the blue dot, so a crafted item's maker isn't taken for it. It opens a page only when MeowDB has an item of that name (allowing for letters the reading confuses, such as I and l); an alert at the top centre of the game window says what came of it: the page it opened, or why nothing opened (no tooltip by the pointer, a name it couldn't read, the panel, the Grind Tracker or the last alert covering the name, no MeowDB item of that name, or MeowDB out of reach). When several items share the name, the alert lists them with their categories for you to pick. The alert goes after a few seconds (half a minute with a list), and clicks pass through it to the game unless it lists items. Like the panel, it hides while another app is in front, such as your browser showing the page it opened. Each name is asked of MeowDB once a week at most, and a search waits until 2 seconds after the last one; these searches are MapleCompass's only requests to MeowDB.

They are ordinary registered hotkeys (no keyboard hook), registered only while the game or one of MapleCompass's windows is in front, so other apps keep their own shortcuts, but the game never sees these combinations. If one clashes with a key you bind in the game, change it in Settings: click the gear at the top of the panel (or Change hotkeys in setup's Overlay Guide, which works from the keyboard), then the hotkey's Change, and press the new combination. Ctrl+Shift with a key is safest: MapleStory attacks with Ctrl and jumps with Alt by default. A combination must hold Ctrl, Alt or Win (a plain key, or Shift and a key, would never reach the game, not even its chat); Esc cancels. If another MapleCompass hotkey has it, Swap trades the two. To stop a hotkey taking its keys from the game at all, turn it off: Turn off, or Backspace or Delete, while it waits. Its button at the top of the panel still works; Item Lookup has no button, so off it can't be used. Every change works at once and is saved, and the line by Restore defaults says what changed; Restore defaults puts every hotkey back, and on, and Undo brings yours back until you change another or close Settings. While MapleCompass waits for keys, the hotkeys are released, so the combination you press reaches Settings rather than acting. Like the search view, Settings has the keyboard while it is open, and closes when you click back into the game. If Windows or another app already has one, or one isn't a key combination, the panel and the setup window say which, and Settings marks the row. Win+Alt hotkeys saved by an earlier version are moved to these.

If you mark the EXP bar at setup, the Grind Tracker opens in a window of its own beside the panel, built like it: Time to Level, your EXP per hour over the last 5 minutes and, once you've played longer, over the whole Session with its length, how your pace compares with the solo EXP/h ceiling of the map you're on (worked out as MeowDB works it out, after a minute there), and deaths. On a map with mobs it also keeps your Personal Best there: the best EXP per hour you've had over 5 minutes of play on that map, with any of your characters. When you come back to a map, a Best row under your rates shows the best from your earlier visits there, from the moment you arrive (before your first EXP gain, it shows on its own), and once you've played 5 minutes there a yellow star marks your last 5 minutes while they beat it. If a best came from a misreading, or from a stretch you can't repeat, the × beside it removes it from your history at once (there is no undo), and your next-best visit takes over. The visit you're on joins your history when you leave the map, and its best can be removed then. Once you have a best anywhere, the star on its bar (or the word Best on the Best row) opens your Personal Bests in your browser: every map's best side by side, highest first with a star on your best of all, with each map's region and mob levels, how close your best came to its solo EXP/h ceiling (and that ceiling), and when you set it, so you can compare maps (bests are shared by all your characters, so the levels say what each was worth). A best on a map that has left the map list stays, marked "Not in the map list". Click a column to sort by it, or a map to open it on MeowDB; the page shows your bests as they were when you opened it, so open it again to see newer ones. At its foot it draws the EXP bar as it last read it, like the game's own gauge, so you can see it is being read; if the bar can't be read for ten seconds (something covers it, or the marked spot no longer frames it), the window says so rather than counting the time as a break. It sits beside the panel with their tops level, so it stays put as the panel grows and shrinks from map to map. Drag it by its bar anywhere, even outside the game window, and it keeps that spot relative to the game; drag it back beside the panel and it follows the panel again. Like the panel, it never covers what MapleCompass reads, and it hides while another app is in front or the game is minimised. The circular arrow beside Time to Level resets the Session, which starts afresh at your next EXP gain; until then, Undo brings the old Session back. There is no hotkey for it, so a stray key press while you fight can't clear it. Its × closes the window (the Session carries on) until you show it again from the panel or with Ctrl+Shift+G. If you switch character, the Session starts afresh by itself and the window says so.

Click the Portals or Mobs heading to collapse that section to its heading, which then says how many it holds (for Portals, how many Hidden Portals; the picture goes too); click it again to open the section. A collapsed section stays collapsed from map to map and the next time you start MapleCompass.

A few maps share a title, such as the two Maple Road / Mushroom Town maps. If they would show the same Map Summary, mobs and hidden portals anyway, the panel just shows them, but without the map's picture, since each has its own layout. Otherwise it picks the one connected to the map you came from, and failing that it shows the first and lists them all, each with its first mobs, mob levels and hidden portal count, with the map ID secondary; Ctrl+Shift+N then steps through them, and your pick holds until you change maps. The picture shows once the map you came from or your pick settles which map you're on.

Many map names differ only in a Roman numeral, such as Rocky Road I, II and III. The recogniser can't read the game font's "II" and "III", so MapleCompass counts their strokes. When a numeral still can't be made out, the panel picks the map the one you came from leads to, if it leads to just one of them; otherwise it says it isn't sure rather than guess.

Inside, the panel keeps the spot you dragged it to relative to the game window. Docked, it follows the game window's outside edge, and goes inside when there is no room on screen. Detached, you can drag it anywhere, such as onto another monitor, and it stays there; it also gets a taskbar entry. Wherever it is placed, even detached on another monitor, it shows on top of everything only while the game or one of MapleCompass's windows is in front, and hides while another app is or the game is minimised.

Settings, including the placement, collapsed sections, the marked title, a hand-picked game window and the hotkeys, are saved in `%APPDATA%\com.itechify.maplecompass\settings.json`. Your Personal Bests, each map's 10 best Visits with when each was set, are saved beside it in `personal-bests.json` as they change, so closing MapleCompass mid-Visit keeps that Visit's best. The Personal Bests page is written beside them as `personal-bests.html` each time you open it. A file that can't be read is renamed `personal-bests.json.bad` and MapleCompass starts with no bests; if it can't be renamed, it is left as it is, and MapleCompass saves no bests until the next launch.

## Credits

Map and mob data, map pictures and mob animations come from [OSMS Data Explorer](https://osmsdataexplorer.com), fetched as it runs and never bundled. Map, mob and item links open [NiaMeowDB](https://meowdb.com)'s pages, and Item Lookup uses its search ([ADR 0007](docs/adr/0007-item-lookup-on-a-hotkey-through-meowdb-search.md)). The Map Summary is worked out as NiaMeowDB works it out.
